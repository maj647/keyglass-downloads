# Keyglass downloads

Keyglass finds the key, BPM and tuning of any beat on your Mac, fully offline.
This page only hosts the installers and update info.

## Download

**[Get the latest version](https://github.com/maj647/keyglass-downloads/releases/latest)**: download the `.dmg` file under *Assets*.

Needs a Mac with Apple Silicon (M1 or newer) and macOS 14.2 or later.

## Install

1. Open the `.dmg` and drag **Keyglass** into **Applications**.
2. Open Keyglass. macOS says it can't check the app, because the beta isn't signed
   with an Apple Developer ID yet. Click **Done**.
3. Open **System Settings > Privacy & Security**, scroll down, click **Open Anyway**
   next to Keyglass, and enter your Mac password. You only do this once.
4. The first launch prepares the analyzer in the background (about a minute).

## Updates

Keyglass checks this page when it's online and shows "Keyglass x.y is available"
in its window. Download the new `.dmg` and drag it into Applications again.
